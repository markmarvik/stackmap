Privacy

StackMap is a static site. There is no account, no sign-up, and no server or database run by the app.

What stays in this browser

The app stores the following only in this browser’s localStorage. It never sends that data anywhere.

  • My Stack: nodes, notes, slots, and the paused flag
  • Personal Corner: age, gender, weight, height, blood pressure, sleep, push-ups, mood, and digestion
  • View settings
  • Any Pro license key

Clearing and export

Clear it by clearing this site’s data in your browser, or remove the saved stack with Clear stack. Export gives you a JSON copy.

Third parties

These services load with the page. Each receives your IP address and user agent when the page loads:

  • GitHub Pages, which hosts the site and may log IP addresses under GitHub’s privacy statement
  • Google Fonts
  • cdnjs, for the Font Awesome icons
  • GoatCounter (gc.zgo.at and stackmap.goatcounter.com), for cookieless analytics

Analytics

StackMap uses GoatCounter, a cookieless, privacy-friendly analytics service. It counts page views and a few anonymous in-app actions (for example "added to stack"), with referrer, browser, screen size and country derived from your IP address. It does not set cookies, does not store your IP address, and receives none of your stack or Personal Corner data. See GoatCounter's privacy policy for details.

Cookies

The app does not set cookies.

Contact

Questions and requests go through GitHub issues. The map is educational only, not medical advice. See the terms.
